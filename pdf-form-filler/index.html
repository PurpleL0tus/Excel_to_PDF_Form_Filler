설명서

Excel 표의 한 행이 PDF 한 개가 됩니다. 같은 양식에 사람마다 다른 내용을 채워 수십 개의 PDF를 한 번에 만들 수 있습니다.

1 문서 준비하기

Word, 한글, PowerPoint 등으로 평소처럼 양식을 만들고, 데이터가 들어갈 자리마다 T@RG3T를 적습니다.

  • Word 파일(.docx)과 PDF를 넣을 수 있습니다. 두 형식은 이렇게 다릅니다.
    Word

    좋은 점

    • Word 파일을 그대로 씁니다.
    • 값이 길면 칸이 늘어나고 줄이 바뀝니다.
    • 값이 문서의 글꼴·크기·색을 그대로 따릅니다.

    아쉬운 점

    • Word에서 보던 것과 모양이 조금 다를 수 있습니다.
    • 결과 PDF의 각 쪽이 그림이라 글자를 선택하거나 검색할 수 없습니다.
    • 처음 쓸 때 Word 기능을 내려받느라 조금 걸립니다.
    PDF

    좋은 점

    • 원본 모양 그대로, 위치가 정확합니다.
    • 결과 PDF의 글자를 선택하고 검색할 수 있습니다.
    • '글자 설정'으로 글꼴·크기·색을 정하고, 긴 값은 칸에 맞게 줄일 수 있습니다.

    아쉬운 점

    • 칸 크기가 고정되어 있어 긴 값은 작아지거나 넘칩니다.
    • 양식을 고치려면 원본을 고친 뒤 다시 PDF로 저장해야 합니다.
  • T@RG3T는 대문자로, 철자 그대로 적어 주세요. 앞뒤에 다른 글자가 붙어 있어도 찾습니다. 예: (T@RG3T일)
  • PDF 편집기의 '텍스트 추가'로 적은 T@RG3T도 찾습니다. 스캔한 PDF(사진)에 있는 글자는 찾을 수 없습니다.
  • 칸 번호는 위에서 아래로, 같은 줄에서는 왼쪽에서 오른쪽 순서로 붙습니다. 오른쪽 미리보기에 빨간 번호로 표시됩니다.
  • 채워지는 글자는 기본적으로 T@RG3T와 같은 크기와 색으로 쓰입니다.
  • 한 줄에 여러 개를 써도 됩니다. 예: T@RG3T / T@RG3T, (T@RG3T일). 각각 다른 칸이 되고, 바로 뒤에 붙은 글자는 값의 길이에 맞춰 함께 옮겨 써서 겹치지 않습니다.
  • 표 안, 여러 쪽짜리 양식도 됩니다. 번호는 1쪽부터 쪽 순서대로 이어집니다.
  • 안 되는 것: 채울 수 있는 PDF 양식 필드 안에 적은 T@RG3T, 비밀번호가 걸린 PDF, 스캔본, 오래된 Word 형식(.doc).

2 데이터 넣기

Excel 파일(.xlsx)을 넣습니다. 한 행이 PDF 한 개가 됩니다.

  • 사용할 시트: 시트가 여러 개면 데이터가 있는 시트를 고릅니다.
  • 열 제목 행: 표 위에 제목이나 메모가 있으면 실제 열 제목(성명, 부서 …)이 있는 행을 고르세요. 그 위의 행은 쓰지 않고, 그 아래 행부터 PDF로 만듭니다. 처음에는 알아서 짐작해 둡니다.
  • Excel에서 숨긴 행과 열은 자동으로 빠집니다.
  • 표가 작아 보이면 표 아래의 크게 보기 버튼(네 모서리 모양)을 누르세요.
  • 만들 행: 모든 행을 만들거나, 일부 행만을 눌러 체크하거나 번호로 고릅니다. 번호는 Excel에 보이는 행 번호입니다. 예: 2-5, 39-44, 90-102
  • 파일 이름으로 쓸 열: 예를 들어 '성명'을 고르면 김민준.pdf처럼 만들어집니다. 이름이 같으면 _2가 붙습니다.
  • 파일 이름에 쓸 수 없는 글자(\ / : * ? " < > |)는 _로 바뀌고, 이름은 100자까지 씁니다. 이름 칸이 비어 있으면 12행.pdf처럼 행 번호를 씁니다. 같은 이름이 여러 번 나오면 홍길동_2.pdf처럼 번호를 붙입니다.
  • 쓸 수 있는 파일: .xlsx, .xlsm. 오래된 Excel 형식(.xls)은 .xlsx로 저장해서 넣어 주세요.
  • 숫자와 날짜는 Excel에 보이는 모양 그대로 들어갑니다. 예: 1,000, 2026-10-30, 50%
  • 병합한 셀은 값이 맨 왼쪽 위 칸에만 있는 것으로 읽힙니다. 나머지 칸은 빈칸입니다.
  • 셀 안의 줄바꿈은 띄어쓰기 한 칸으로 바뀝니다.
  • 빈 셀이 연결된 칸은 비워 둡니다. 고른 열이 모두 비어 있는 행은 PDF를 만들지 않고 건너뜁니다.

3 열과 칸 연결하기

문서의 각 칸(#1, #2 …)에 어떤 열의 값이 들어갈지 정합니다.

  • 처음에는 #1 ← A열, #2 ← B열 … 순서대로 연결되어 있습니다. 맞으면 그대로 두고, 다른 칸만 바꾸면 됩니다.
  • 같은 열을 여러 칸에 써도 됩니다.
  • 오른쪽의 첫 행 값으로 무엇이 들어갈지 바로 확인할 수 있습니다. 칸 위에 마우스를 올리면 미리보기에서 그 칸이 강조됩니다.
  • 글자 설정: Noto Sans KR 글꼴 굵기 9가지 중에서 고르거나 내 글꼴 파일(.ttf, .otf)을 쓸 수 있습니다. 글자 크기와 색을 한 가지로 맞출 수도 있고, 긴 글자를 칸에 맞게 줄일지도 정합니다.
  • 긴 글자 줄이기를 켜 두면 칸에 들어갈 때까지 0.5pt씩, 최소 6pt까지 줄입니다. 그래도 넘치면 어느 행, 어느 칸인지 알려 줍니다.

계산한 값 넣기 (수식)

칸 옆의 계산기 버튼을 누르고 계산식을 적습니다. 다시 누르거나 목록에서 열을 고르면 원래대로 돌아갑니다.

(A+D-CI)*4*CD  →  (A열 + D열 − CI열) × 4 × CD열
  • 열 글자(A, B, CI …), 숫자, 괄호와 + - * /를 쓸 수 있습니다. 곱하기는 *, 나누기는 /입니다.
  • 거듭제곱은 ^입니다. 예: B^2는 B열의 제곱. 퍼센트도 됩니다. 예: B*15%
  • Excel과 같은 함수를 쓸 수 있습니다. 값은 쉼표로 나눕니다.
    ROUND(A/3, 2)소수 둘째 자리로 반올림 (ROUNDUP 올림, ROUNDDOWN 내림)
    SUM(A, B, C)합계 (AVERAGE 평균, MIN 가장 작은 값, MAX 가장 큰 값)
    ABS(A-B)절댓값 (INT 소수점 아래 버림, SQRT 제곱근)
    MOD(A, 7)나눈 나머지
  • 1,000, ₩3,000원, 10%, 3일, 2.5 시간처럼 단위가 붙은 값도 숫자만 읽습니다. 빈 칸은 0으로 계산합니다. 날짜나 전화번호처럼 숫자가 여러 개 들어 있는 값은 계산할 수 없습니다.
  • 계산 결과 뒤에 글자를 붙이려면 옆의 뒤에 붙일 글자 칸에 적습니다. 예: 계산식 2*15, 붙일 글자 원 → 30원. 적은 그대로 띄어쓰기 없이 붙습니다.
  • 계산할 수 없는 행(예: 숫자 칸에 글자가 있음)이 있으면 몇 행인지 알려 줍니다. Excel에서 고치거나 2단계의 만들 행에서 그 행을 빼세요.

4 PDF 만들기

  • PDF ○개 만들기를 누르면 모든 PDF가 ZIP 파일 하나로 저장됩니다. 1~3단계를 모두 마치면 버튼을 누를 수 있습니다.
  • ZIP 파일 이름은 문서이름_완성.zip입니다.
  • 수백 행도 한 번에 만들 수 있습니다. 행이 많을수록 시간이 걸리고, 진행 막대로 몇 번째인지 보여 줍니다.

? 잘 안 될 때

T@RG3T를 찾지 못했다고 나와요
대문자로 정확히 적었는지 확인하세요. 스캔한 문서나 그림으로 된 글자는 찾을 수 없습니다. 원본 문서에서 다시 'PDF로 저장'해 보세요.
일부 글자가 빠져요
고른 글꼴에 없는 글자입니다. 미리보기 아래에 빠지는 글자가 표시됩니다. '글자 설정'에서 그 글자가 있는 내 글꼴 파일을 고르세요.
글자 위치가 조금 어긋나요
Word 파일을 넣었다면, Word에서 'PDF로 저장'한 파일을 넣어 보세요. 가장 정확합니다.
엉뚱한 값이 들어가요
2단계의 '열 제목 행'이 맞는지, 3단계에서 각 칸에 맞는 열을 골랐는지 확인하세요.
ZIP 파일이 받아지지 않아요
다운로드 확인 창에서 허용을 눌렀는지 확인하세요. 그래도 안 되면 이 페이지를 브라우저의 새 탭에서 열어 다시 해 보세요.
날짜나 숫자 모양이 Excel과 달라요
흔히 쓰는 서식은 Excel과 똑같이 보여 줍니다. 특이한 서식이라면 Excel에서 =TEXT(A2, "yyyy년 m월 d일")처럼 원하는 모양의 글자로 바꾼 열을 만들어 그 열을 연결하세요.
Word로 만든 PDF에서 글자가 선택되지 않아요
Word 문서는 각 쪽을 그림으로 찍어 PDF를 만들기 때문입니다. 글자를 선택하거나 검색해야 한다면 Word에서 'PDF로 저장'한 문서를 쓰세요.

예시 파일 받기

위에서 본 예시 양식(PDF)과 예시 데이터(Excel)를 한 번에 받습니다. 양식은 1단계에, 데이터는 2단계에 넣어 보세요.

Each row of an Excel sheet becomes one PDF. Fill the same form with different details for each person and make dozens of PDFs at once.

1 Prepare the document

Make the form as usual in Word, PowerPoint or any other program, and type T@RG3T wherever data should go.

  • Word files (.docx) and PDFs can both be used. This is how they differ:
    Word

    Good

    • Use the Word file as it is.
    • Long values make the space grow and wrap onto new lines.
    • Values take the document's own font, size and colour.

    Not so good

    • Can look slightly different from how it looks in Word.
    • Each page of the finished PDF is a picture, so text can't be selected or searched.
    • The first time takes a little longer while the Word feature downloads.
    PDF

    Good

    • Looks exactly like the original, with exact positions.
    • Text in the finished PDFs can be selected and searched.
    • Choose the font, size and colour in "Text settings", and shrink long values to fit.

    Not so good

    • Boxes are a fixed size, so long values shrink or run over.
    • To change the form, edit the original and save it as a PDF again.
  • Type T@RG3T in capitals, spelled exactly like this. It is found even with other characters right next to it, for example (T@RG3T days).
  • T@RG3T added with a PDF editor's "Add text" tool is found too. Text in a scanned PDF (a picture) can't be found.
  • Boxes are numbered top to bottom, and left to right on the same line. The red numbers in the preview on the right show the order.
  • By default the filled-in text uses the same size and colour as the T@RG3T it replaces.
  • Several on one line are fine, for example T@RG3T / T@RG3T or (T@RG3T days). Each is its own box, and text glued right after it is moved along with the value so nothing overlaps.
  • Documents with tables and several pages work too. Numbering continues page by page, starting on page 1.
  • Not supported: T@RG3T typed inside fillable PDF form fields, password-protected PDFs, scans, and the old Word format (.doc).

2 Add the data

Add an Excel file (.xlsx). Each row becomes one PDF.

  • Sheet: if the file has several sheets, choose the one with the data.
  • Title row: if there is a heading or notes above the table, choose the row with the real column titles (Name, Department …). Rows above it are ignored, and the rows below it become PDFs. A best guess is made for you at first.
  • Rows and columns hidden in Excel are left out automatically.
  • If the table looks small, press the enlarge button (four corners) under it.
  • Rows to make: make every row, or press Some rows and tick them or type their numbers. These are the row numbers shown in Excel, for example 2-5, 39-44, 90-102.
  • File name column: for example, choosing "Name" gives files like James Carter.pdf. Repeated names get _2 added.
  • Characters that can't be used in file names (\ / : * ? " < > |) become _, and names are kept to 100 characters. If the name cell is empty, the row number is used, like row 12.pdf. If a name appears more than once, a number is added, like Jane Smith_2.pdf.
  • Files that work: .xlsx and .xlsm. Save old Excel files (.xls) as .xlsx first.
  • Numbers and dates go in exactly as Excel shows them, for example 1,000, 2026-10-30, 50%.
  • Merged cells are read as having their value only in the top-left cell; the other cells are empty.
  • Line breaks inside a cell become a single space.
  • A box linked to an empty cell is left blank. Rows where every chosen column is empty are skipped, so no PDF is made for them.

3 Match columns to boxes

Choose which column goes into each box of the document (#1, #2 …).

  • At first they are matched in order: #1 ← column A, #2 ← column B … If that's right, leave it and change only the boxes that differ.
  • The same column can be used in several boxes.
  • The first row column on the right shows what will go in. Hover over a box to highlight it in the preview.
  • Text settings: choose one of nine Noto Sans KR weights or use your own font file (.ttf, .otf). You can also set one size and colour for all text, and choose whether long text shrinks to fit its box.
  • With Shrink long text on, text is made 0.5 pt smaller at a time, down to 6 pt, until it fits. If it still doesn't fit, you are told which row and box.

Calculated values (formulas)

Press the calculator button next to a box and type the calculation. Press it again, or pick a column from the menu, to go back.

(A+D-CI)*4*CD  →  (column A + column D − column CI) × 4 × column CD
  • Use column letters (A, B, CI …), numbers, brackets and + - * /. Multiply with * and divide with /.
  • Powers use ^: B^2 is column B squared. Percentages work too: B*15%
  • The same functions as in Excel can be used, with values separated by commas.
    ROUND(A/3, 2)Round to 2 decimal places (ROUNDUP rounds up, ROUNDDOWN down)
    SUM(A, B, C)Total (AVERAGE, MIN smallest, MAX largest)
    ABS(A-B)Value without its sign (INT drops the decimals, SQRT square root)
    MOD(A, 7)Remainder after dividing
  • Values with units, like 1,000, $3,000, 10%, 3 days or 2.5 hours, are read as their number. Empty cells count as 0. Values with several numbers in them, like dates or phone numbers, can't be calculated.
  • To put text after the result, type it in the Text after box next to the formula. For example: formula 2*15, text pound → 30pound. It is added exactly as typed, with no space in between.
  • If a row can't be calculated (for example, text in a number column), you are told which row. Fix it in Excel or leave that row out under Rows to make in step 2.

4 Make the PDFs

  • Press Make ○ PDFs to save every PDF in one ZIP file. The button becomes available once steps 1–3 are done.
  • The ZIP file is named documentname_filled.zip.
  • Hundreds of rows can be made in one go. More rows take longer, and a progress bar shows how far along it is.

? If something goes wrong

It says no T@RG3T was found
Check that it is typed exactly, in capitals. Text in scans or pictures can't be found. Save the original document as a PDF again.
Some characters are missing
They are not in the chosen font; the missing characters are listed under the preview. Choose a font file that has them in "Text settings".
Text is slightly out of place
If you used a Word file, try a PDF saved from Word instead. That is the most accurate.
The wrong values go in
Check that the "Title row" in step 2 is right and that each box has the right column in step 3.
The ZIP file doesn't download
Check that you allowed it in the download prompt. If it still fails, open this page in a new browser tab and try again.
Dates or numbers look different from Excel
Common formats look exactly as they do in Excel. For an unusual one, make a column in Excel with the text you want, for example =TEXT(A2, "mmmm d, yyyy"), and link that column instead.
I can't select text in PDFs made from Word
A Word document is turned into a picture of each page. If the text needs to be selectable or searchable, use a document saved as PDF from Word.

Download the example files

Get the example form (PDF) and example data (Excel) shown above in one download. Put the form in step 1 and the data in step 2.

보안정보

내 파일은 안전한가요?

네. 모든 작업은 컴퓨터 안에서, 오프라인으로 처리됩니다. 넣은 문서와 데이터는 인터넷으로 보내지지 않고, 어떤 서버에도 올라가지 않습니다.

파일을 받는 서버가 없습니다

많은 온라인 변환 사이트는 파일을 회사 서버에 올려서 처리합니다. 이 도구는 다릅니다. 파일을 받는 서버가 처음부터 없고, 파일을 읽고, T@RG3T 자리를 찾고, 값을 채워 PDF를 만드는 일까지 모두 컴퓨터가 직접 합니다.

인터넷은 페이지를 열 때만 씁니다

페이지를 열 때 화면, PDF를 읽고 만드는 도구, 글꼴을 내려받습니다. 일반 웹페이지를 여는 것과 같으며, 이때도 받아 오기만 할 뿐 내 파일이나 그 내용은 보내지 않습니다. 한 번 열린 뒤에는 인터넷이 끊겨도 그대로 작동합니다. 아직 받지 않은 다른 굵기의 글꼴이나 Word 기능을 처음 쓸 때만 그 도구를 한 번 더 내려받습니다.

아무것도 남기지 않습니다

넣은 파일, 미리보기, 만든 PDF는 이 창이 열려 있는 동안만 컴퓨터 메모리에 있다가 창을 닫으면 사라집니다. 이 도구는 내 파일의 내용도, 사용 기록도 모으지 않습니다. 기억하는 것은 고른 언어 하나뿐이며, 그것도 컴퓨터의 브라우저에만 저장됩니다.

Are my files safe?

Yes. Everything is processed locally, on your own computer, offline. Your documents and data are never sent over the internet and never uploaded to any server.

There is no server that receives files

Many online converters upload your files to a company's server to process them. This tool doesn't. There is no server to receive files in the first place: reading your files, finding each T@RG3T, filling in the values and making the PDFs is all done by your own computer.

The internet is only used to open the page

When the page opens, it downloads the screen, the tools that read and write PDFs, and the fonts. That's the same as opening any web page, and it only downloads; your files and their contents are never sent. Once the page is open, it keeps working even if the internet goes down. The only extra downloads happen the first time you pick another font weight or use the Word feature.

Nothing is kept

Your files, the previews and the finished PDFs only exist in your computer's memory while this window is open, and they're gone when you close it. The tool collects neither your file contents nor any record of how you use it. The only thing remembered is your language choice, and that is stored only in your own browser.

Results are saved to your computer

The finished PDFs are packed into one ZIP file on your computer and, once you allow it in the download prompt, saved to your computer's downloads folder.

Nothing goes to the AI either

This tool was made with Claude, but the AI never sees or reads the files you add. The tool has no feature that sends anything to the AI.

It is kept apart from everything else

The page opens in its own isolated space, so it can't reach your Claude chats, your account or information from other websites.
